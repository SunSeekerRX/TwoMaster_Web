# TwoMaster_Web

Two Master 5.9.62 网页试玩版。

游玩地址：https://sunseekerrx.github.io/TwoMaster_Web/

## 使用说明

- 使用桌面浏览器打开游玩地址，等待首次加载完成。
- 网页首页仅约 2 KB，首次加载并行下载约 366 MB 压缩资源，显示实际进度。
- 下载中断自动重试，完成的资源分块缓存在浏览器中。再次打开无需重新下载已缓存资源。
- 当前网页版尚不支持原有局域网联机。
- 本版包含更新后的 100 张技能、36 件装备和 30 颗宝石图标。

2026-10-24 公网 Edge 实测：首次约 10 分 53 秒，缓存复开约 8.2 秒且游戏资源零重复下载。实际完成选人、布阵、领取补给、施法、AI 回合与刷新后恢复存档。首次速度受网络影响较大，资源体积仍需后续进一步优化。

## 发布结构

游戏文件无损压缩后保存在 Release `v5.9.62` 的 12 个 `TwoMaster.html.gz.partXX` 附件中。
GitHub Actions 下载并合并分片，校验原 HTML 的 SHA-256，提取原始 Unity 二进制资源，生成独立压缩分块和加载首页，再发布到 GitHub Pages。游戏二进制内容不变。
仓库不包含 Unity 工程。

重新部署：在 Actions 中打开 `Publish Two Master Web`，选择 `Run workflow`。
更新游戏版本时，需要同时更新 Release 标签、工作流下载地址及 SHA-256。
